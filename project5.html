Mine a Database: PubMed XML to Relational and Analytical Database Transformation

Spring 2024

SQLite MySQL R Programming

Project Overview

This project bridges transactional and analytical processing by integrating OLTP and OLAP methodologies to transform XML-based publication metadata into structured, queryable formats. The workflow begins with parsing and cleaning metadata using R and XPath, followed by storing it in a relational schema using SQLite. Finally, a star schema is implemented in MySQL for complex OLAP-style queries to extract meaningful trends.

Key Features

  • Designed both normalized schemas (OLTP) for integrity and star schemas (OLAP) for efficient analytical querying.
  • Used R programming and XPath to extract structured data from unstructured XML sources.
  • Wrote optimized SQL queries to analyze trends in publication dates, authorship patterns, and metadata quality over time.

Technologies Used

  • SQLite: Used for initial schema design and ingesting cleaned metadata in an OLTP structure.
  • MySQL: Hosted the OLAP star schema and enabled multi-dimensional analysis.
  • R Programming: Performed XML parsing, data transformation, and export to SQL-ready formats.
