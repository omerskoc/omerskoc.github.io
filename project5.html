PubMed Data Mining

Spring 2024

SQLite MySQL R Programming

Overview

This project integrates OLTP and OLAP methodologies to transform XML-based metadata into actionable insights, leveraging relational schema design and advanced analytical queries.

Key Features

  • Normalized and star schema design for efficient query processing.
  • Data parsing and transformation using R and XPath techniques.
  • Analytical queries for insights into publication trends.

Technologies

  • SQLite: Schema design and data ingestion.
  • MySQL: OLAP schema and analytical queries.
  • R: XML parsing and data manipulation.
