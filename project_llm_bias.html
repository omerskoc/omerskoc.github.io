Bias Detection in Large Language Models

Spring 2025

Python Ethical AI Bias Detection TF-IDF Sentiment

Introduction to LLM Bias Evaluation

Large Language Models (LLMs) like ChatGPT, Copilot, and DeepSeek shape how information is generated and consumed. This project evaluates how these models handle sensitive topics such as gender, race, socio-economic status, and politics by analyzing over 400 structured prompts. The goal is to uncover hidden biases and promote more transparent AI systems.

Implementation Highlights

  • Prompt Engineering: 400 prompts created across four bias types (gender, race, SES, politics) with varied task formats.
  • Data Collection: Responses gathered manually and via automation, stored in structured CSV files.
  • Bias Metrics: Sentiment polarity, TF-IDF, subjectivity, stereotype detection, and agency scoring applied in Python.
  • Model Comparison: Response differences visualized to highlight language trends and framing tendencies.

Findings and Achievements

  • Bias Detected: Models used male-coded language in leadership roles and showed liberal leanings in political framing.
  • High Agreement: Over 90% consistency in multiple-choice tasks despite different sentiment tones.
  • Impactful Visuals: Word clouds and bar graphs illustrated language biases and thematic patterns.
  • Reproducibility: Fully open-source pipeline enables replication and future research in AI fairness.
