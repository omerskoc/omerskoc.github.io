Cloud Architecture for Cafe Business on AWS

Fall 2024

AWS Cloud Computing

Project Overview

Developed a scalable and secure cloud solution for a hypothetical café business using AWS services. This project focused on leveraging cloud technologies to create an infrastructure that supports high availability, cost optimization, and operational efficiency.

Implementation Details

  • Utilized AWS services including EC2, S3, and RDS for hosting and data management.
  • Implemented cost optimization techniques such as reserved instances and lifecycle policies.
  • Ensured high availability with load balancers and multi-AZ deployments.
  • Automated infrastructure management using AWS CloudFormation.

Key Outcomes

  • Established a robust and secure cloud architecture suitable for business-critical operations.
  • Reduced operational costs while maintaining high performance.
  • Demonstrated best practices in cloud design, automation, and security.
