Bird Strike: Design & Implement a Relational Database

Spring 2024

MySQL R Programming Data Analysis

Project Overview

This project focuses on designing and implementing a relational database system to manage and analyze bird strike incidents in the aviation industry. Using MySQL for structured data storage and R programming for data manipulation and visualization, the system aims to enhance aviation safety by uncovering trends, identifying high-risk factors, and providing actionable insights to decision-makers.

Key Features

  • Designed relational tables for core entities including incidents, airports, airlines, and environmental conditions.
  • Enforced referential integrity through primary and foreign keys to maintain clean, interconnected data.
  • Developed complex SQL queries to extract meaningful patterns, such as states with the highest frequency of bird strikes, most affected airlines, and correlations with flight phases or environmental conditions.
  • Created data visualizations in R to present trends and risk factors clearly to stakeholders and support data-driven safety strategies.

Technologies Used

  • MySQL: Designed and managed a relational database schema for efficient storage and querying.
  • SQL: Used to extract, aggregate, and analyze data patterns across multiple dimensions.
  • R Programming: Employed for data cleaning, statistical analysis, and generating visual outputs such as bar charts, heatmaps, and time series plots.
