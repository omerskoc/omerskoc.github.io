Bird Strike Database Management Project

Spring 2024

MySQL R Programming Data Analysis

Overview

This project focuses on creating a relational database system for managing and analyzing bird strike incidents using MySQL and R Programming. The system is designed to improve aviation safety by identifying trends and providing actionable insights through efficient data management and visualization.

Key Features

The project includes the creation of relational tables for incidents, airports, airlines, and conditions, ensuring clean and interconnected data. SQL queries are used to uncover patterns such as high-risk states and airlines, while visualizations help stakeholders understand the data effectively.

Technologies

This project employs a blend of tools and technologies:

  • MySQL: Reliable database management with relational schema design.
  • R Programming: Data manipulation, cleaning, and visualization.
  • SQL: Optimized queries for data analysis and reporting.

For a detailed overview of the project, check out the project report, or view the R implementation code.
